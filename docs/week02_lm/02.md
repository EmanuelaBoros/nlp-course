## Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/EmanuelaBoros/nlp-course.git
```

Then move into the course folder:

```bash
cd nlp-course/docs/week02_lm
```

### Open the Notebook

Start Jupyter Notebook:
```bash
jupyter notebook
```

Then open: `seminar.ipynb`, `homework_pytorch.ipynb`
