## Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/EmanuelaBoros/nlp-course.git
```

Then move into the course folder:

```bash
cd nlp-course/docs/week03_attention
```

### Open the Notebook

Start Jupyter Notebook:
```bash
jupyter notebook
```

Then open: `new_practice_and_homework.ipynb`
